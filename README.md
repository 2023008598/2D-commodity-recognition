# 2D Commodity Recognition: End-to-End Pipeline

This repository implements an end-to-end, two-stage deep learning pipeline for commodity recognition in complex visual environments. 

## Project Overview
The system architecture mimics real-world industrial visual recognition workflows, cascading two state-of-the-art models:
1. **Stage 1 (Detection):** Leverages **YOLO11** to accurately localize commodities within cluttered scene images, outputting bounding boxes (Regions of Interest, ROIs) and initial confidence scores.
2. **Stage 2 (Classification):** Utilizes **ConvNeXt V2** to perform fine-grained classification on the cropped ROIs provided by the detector, determining the exact commodity category.

## Deep Dive: Error Propagation Analysis
A major focus of this project is understanding and quantifying the "Cascading Error" effect inherent in two-stage pipelines. 

To evaluate this, the ConvNeXt V2 classifier's performance was tested under two distinct conditions:
* **GT-ROI (Ground Truth):** Classification based on perfect, human-annotated bounding boxes. This establishes the theoretical upper-bound performance of the classification network.
* **Pred-ROI (Predicted):** Classification based on the bounding boxes generated by the YOLO11 detector in Stage 1. This reflects the true end-to-end system capability.

**Key Insight:** The empirical gap between GT-ROI and Pred-ROI accuracy explicitly reveals how minor upstream localization errors (e.g., box shifts, partial truncations, false positives) act as **severe semantic noise** downstream. This analysis demonstrates that optimizing a pipeline requires more than just maximizing individual model metrics; it demands a holistic approach to data quality, threshold tuning, and error mitigation across interconnected modules.

## Repository Structure
To maintain a clean and professional open-source footprint, this repository includes the core execution scripts and evaluation artifacts:
* `train.py` & `train_classifier.py`: Training routines for the YOLO11 detector and ConvNeXt V2 classifier.
* `crop_*.py`: Data pipeline scripts for generating GT-ROIs and dynamic Pred-ROIs.
* `eval_end2end.py`: End-to-end joint evaluation script calculating the ultimate system accuracy (Detection + Classification).
* `/results`: Contains training curves, performance metrics, and critical visualizations of failure cases (e.g., bounding box shifts, occlusions).
