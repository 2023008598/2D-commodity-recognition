# 2D Commodity Recognition: End-to-End Pipeline

[cite_start]This repository implements an end-to-end, two-stage deep learning pipeline for commodity recognition in complex visual environments. 

## Project Overview
The system architecture mimics real-world industrial visual recognition workflows, cascading two state-of-the-art models:
1. [cite_start]**Stage 1 (Detection):** Leverages **YOLO11** to accurately localize commodities within cluttered scene images, outputting bounding boxes (Regions of Interest, ROIs) and initial confidence scores[cite: 61, 71, 73].
2. [cite_start]**Stage 2 (Classification):** Utilizes **ConvNeXt V2** to perform fine-grained classification on the cropped ROIs provided by the detector, determining the exact commodity category[cite: 62, 76].

## Deep Dive: Error Propagation Analysis
A major focus of this project is understanding and quantifying the "Cascading Error" effect inherent in two-stage pipelines. 

[cite_start]To evaluate this, the ConvNeXt V2 classifier's performance was tested under two distinct conditions[cite: 135]:
* [cite_start]**GT-ROI (Ground Truth):** Classification based on perfect, human-annotated bounding boxes[cite: 105]. [cite_start]This establishes the theoretical upper-bound performance of the classification network[cite: 118].
* [cite_start]**Pred-ROI (Predicted):** Classification based on the bounding boxes generated by the YOLO11 detector in Stage 1[cite: 106]. [cite_start]This reflects the true end-to-end system capability[cite: 120].

[cite_start]**Key Insight:** The empirical gap between GT-ROI and Pred-ROI accuracy explicitly reveals how minor upstream localization errors (e.g., box shifts, partial truncations, false positives) act as **severe semantic noise** downstream[cite: 66, 98, 125]. [cite_start]This analysis demonstrates that optimizing a pipeline requires more than just maximizing individual model metrics; it demands a holistic approach to data quality, threshold tuning, and error mitigation across interconnected modules[cite: 127].

## Repository Structure
[cite_start]To maintain a clean and professional open-source footprint, this repository includes the core execution scripts and evaluation artifacts[cite: 130]:
* `train.py` & `train_classifier.py`: Training routines for the YOLO11 detector and ConvNeXt V2 classifier.
* `crop_*.py`: Data pipeline scripts for generating GT-ROIs and dynamic Pred-ROIs.
* [cite_start]`eval_end2end.py`: End-to-end joint evaluation script calculating the ultimate system accuracy (Detection + Classification)[cite: 97, 122].
* [cite_start]`/results`: Contains training curves, performance metrics, and critical visualizations of failure cases (e.g., bounding box shifts, occlusions)[cite: 131, 133, 137].
